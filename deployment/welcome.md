# Welcome to Dungeon Shooter Maker

Welcome! This is the public documentation and support community for Dungeon Shooter Maker.

- Start with the [manual](https://hyunter777.github.io/dungeon-shooter-maker-docs/) and [quick start](https://hyunter777.github.io/dungeon-shooter-maker-docs/quick-start/).
- Ask usage, content-authoring and integration questions in [Q&A](https://github.com/hyunter777/dungeon-shooter-maker-docs/discussions/categories/q-a). Mark the reply that solves your question as the answer.
- Report reproducible defects in [Issues](https://github.com/hyunter777/dungeon-shooter-maker-docs/issues), using the bug report form.
- Publisher: [FlyCat](https://www.flycat.co.kr).

Include the product and Unity versions, render pipeline, OS, the content id or editor window involved and clear
reproduction steps when relevant. Public posts are visible to everyone: remove private information and do not upload
the purchased package, implementation, sample content as a package, paid assets or fonts. For private details,
contact hyunter@flycat.co.kr.

This repository provides documentation and support resources. The product's Unity project and paid contents are
distributed separately under their product license.
